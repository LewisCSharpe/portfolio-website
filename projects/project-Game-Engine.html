Game Engine

Overview

For this project I developed a custom game engine from the ground up using C++ and OpenGL with a modular ECS architecture designed for general use. I used my existing work with 3d graphics and physics integrating them into a unified engine.

Key Features

  • Custom Entity Component System
  • User friendly graphical editor interface (Dear ImGui)
  • 3D rendering (Models, Textures, Shaders)
  • Postprocessing
  • Lighting support (Point lights and cube mapping)
  • Basic physics with rigidbodies and collisions
  • Environmental audio system
  • Scripting support
  • Resource system for managing game assets

What I Learned

Through this project, I gained a much better understanding of engine architecture and the different systems that come together to make a game engine work. I learnt more about the Entity Component System (ECS) approach, and how separating entities, components and systems can make a project more modular and easier to manage. It also helped strengthen my knowledge of 3D graphics, while giving me practical experience with C++ memory management and object lifetimes, particularly through the use of smart pointers.

Overall, the project helped me build confidence working with more complex C++ and gave me a better appreciation of the challenges involved in developing a game engine from the ground up.
