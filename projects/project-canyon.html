Procedural Canyon Terrain Generation

TIGA Most Outstanding Graduate of the Year: Programmer - 2026 - Shortlisted

Overview

Procedural canyon terrain generation created in Unity as part of my final-year university dissertation. The project features a dynamic chunk-based loading system that generates terrain around the player as they move, along with a system for generating a continuous river path through the terrain.

The generation system includes various optimisations to help make it suitable for use in a game. Basic player movement and collision mechanics are also implemented to demonstrate the terrain generation in action.

For more detail check out my dissertation at the bottom of the page.

Key Features

  • Multithreaded chunk-based terrain generation
  • A* pathfinding through chunk heightmaps for continuous river path generation, utilising path smoothing and river carve parameters
  • Multi-Octave Perlin noise for heightmap generation
  • Mesh generation from heightmaps
  • Dynamic distance based mesh Level of Detail
  • Frustum culling of terrain chunks
  • Terrain collider generation
  • Environmental prop scattering
  • Custom canyon terrain shader
  • Gameplay implementation for a playable demo

What I Learned

Working on this project gave me a much better understanding of procedural terrain generation as a whole, from researching techniques like erosion and combining noise functions to experimenting with Perlin noise and its parameters to create the terrain I wanted.

I also became more confident with multithreading and optimisation techniques such as frustum culling and distance-based level of detail (LOD). Alongside this, I used my previous knowledge and applied the A* pathfinding algorithm in a new environment. I've also improved my familiarity and skills within the unity game engine as well as played around with new tools such as unity's shadergraph.
