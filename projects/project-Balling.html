Balling Game

Overview

As part of a first-year university assignment, I developed a game using the Unity game engine. The game is set in a warehouse, where the player controls a ball and earns points by disrupting objects, either by knocking them over or moving them out of place. The aim is to score as many points as possible before the time runs out, while avoiding the NPC forklifts driving around the level. I also created all of the 3D assets used in the game myself.

Key Features

  • Object disruption system (position and rotation checks)
  • AI path controllers
  • Player movement

What I Learned

Throughout this project, I developed my skills and confidence in C# scripting and working with the Unity game engine. It also gave me the opportunity to explore level design and 3D modelling, helping me build a better understanding of different areas of game development. These skills and knowledge will be useful to me as a programmer, as they give me a wider understanding of the processes involved in creating a game.
