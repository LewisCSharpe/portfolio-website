Chat App

Overview

For this project, I developed a basic chat application using C++ and Winsock. The app allows users to send and receive messages between different devices over a network. It uses network sockets to establish connections and handle communication between users.

Key Features

  • Allows users to send and receive messages over a network
  • Direct messaging
  • Usernames
  • Lightweight simple UI
  • Easy hosting and joining with IP addresses

What I Learned

Through this project, I gained a better understanding of networking and how devices communicate using sockets. I learnt how to use Winsock to establish connections and send and receive data, as well as gaining experience with client-server communication. I also researched ways to improve the app, particularly using encryption such as TLS to make messages more secure.
