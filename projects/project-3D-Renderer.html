3D Renderer

Overview

For this project, I created a standalone 3D renderer from scratch using OpenGL and SDL2. The main focus was on developing the core functionality needed to render 3D objects, including drawing objects to the screen, applying transformations using matrices, and implementing shader support. I also created my own custom shaders in GLSL, including a lighting shader to add basic lighting effects.

The renderer was designed to act as a standalone graphics library to be integrated into my game engine project.

Key Features

  • Rendering of 3D models and primitives
  • Diffuse and specular lighting with multiple light support
  • Shader support with custom shaders
  • Bloom postprocessing
  • Transparency support
  • UI support
  • Demo gameplay implementation

What I Learned

This project taught me a lot about the fundamentals of 3D rendering and the maths behind it. I developed a strong understanding of how objects are drawn, how transform matrices work, and how basic post-processing is implemented.

I also gained a much better understanding of shaders and how powerful they can be. I developed my skills in writing my own basic shaders in GLSL, including learning how diffuse and specular lighting work and how to implement them.

Overall, this project helped strengthen my C++ skills while giving me a much better understanding of what goes on behind the scenes when rendering.
