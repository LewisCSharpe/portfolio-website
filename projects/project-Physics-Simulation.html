Physics Simulation

Overview

For this project I developed a basic 3D physics engine simulating rigid body dynamics, collision detection and response as well as both linear and angular motion with various integration methods. The project includes various demos displaying my physics implementation. The physics engine is designed to be completely standalone so it can later be implemented into a game engine.

Key Features

  • Rigid body dynamics
  • Linear and Angular motion
  • Various integration methods (Euler, RK2, RK4, Verlet)
  • Collision detection and impulse based response
  • Friction simulation

What I Learned

I learnt a lot about the fundamental maths behind physics simulations and developed my skills in implementing mathematics and concepts into code. I also explored different approaches to implementing physics, as well as researching optimisation techniques such as spatial partitioning to improve performance.
